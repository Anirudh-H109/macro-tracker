Macro Event Impact Tracker 
A web app, which in simple terms, helps establish connections between macro events and the related cross-asset market reactions.

V1 pulls data from two sources:

1) FRED (Federal Reserve Economic Data) — CPI, Fed Funds Rate, and Unemployment Rate since 2020

2) yfinance (Yahoo Finance) — SPY intraday and EUR/USD on the April 10 2026 CPI release date

Also includes a CPI surprise score table showing whether recent prints beat or missed analyst expectations and by how much (surprise).

V2 adds:

1) Interactive dropdown to select any CPI release date

2) NFP (Non-Farm Payrolls) monthly jobs chart

3) TLT bonds chart

4) Colour coded CPI surprise score bar chart

5) Automatic fallback to daily data for dates older than 60 days

Link : https://macro-tracker-v1.streamlit.app/
